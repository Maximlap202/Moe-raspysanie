# Моё расписание

Школьное расписание с живым виджетом.

## Возможности
- анимированный фон карточки (снег, дождь, угли, океан…)
- свой фон на каждый предмет
- имя педагога
- размер виджета: маленький / средний / большой
- редактор уроков по дням (Пн–Вс)
- тёмная и светлая тема
- сохранение в localStorage браузера

## Установка и запуск

Нужны Node.js 18+ и npm.

```bash
cd moe-raspisanie
npm install
npm run dev
```

Открой в браузере адрес из терминала (обычно http://localhost:5173).

## Сборка

```bash
npm run build
npm run preview
```

## Про APK

Это веб-проект (React + Vite + Tailwind).

Чтобы получить APK:
1. `npm run build` → папка `dist/`
2. Оберни через [Capacitor](https://capacitorjs.com/) или [PWA Builder](https://www.pwabuilder.com/)
3. Или «Добавить на экран Домой» из мобильного браузера

Нативный Android-виджет на главный экран — отдельный модуль (App Widget).
